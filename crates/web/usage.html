null-term 使い方

パソコン通信用の 2 画面シリアルターミナルを、ブラウザだけで動かせる版です。インストールは要りません。

null-term を開く

必要なもの

  • ブラウザ: Chrome / Edge などの Chromium 系 (デスクトップ)。Safari / Firefox は Web Serial に対応していません
  • つなぐ相手 (どちらか)
    • USB で挿すシリアル機器: USB-UART 変換ケーブルの先のモデム、Arduino、ESP32、M5Stack など
    • 機器がなければ null-bbs (パソコン通信のホスト局) に WebSocket で直接つなげます → 機器なしで試す

画面の見かた

画面は上 (A) と下 (B) に分かれた、独立した 2 台の端末です。下はログではありません。A と B にそれぞれ別の回線をつなげます (モデム 2 台を疑似交換機でつないで、A から B に電話をかける使い方を想定しています)。

  • 各画面の一番上の行に、接続状態 (● 接続 / ○ 未接続)・ポート・bps・データ形式・文字コード・送受信バイト数が出ます
  • 操作するのは ▶ が付いている画面です。Ctrl-A Tab で切り替えます
  • 1 画面で使うときは Ctrl-A z で、今の画面を全体に広げられます

操作の基本: Ctrl-A のあとにキー

キー入力はそのまま相手に送られます。null-term 自体の操作は、Ctrl-A を押して離してから、続けてもう 1 つキーを押します。例えば Ctrl-A → ? でヘルプが出ます。

シリアル機器につなぐ

  1. 機器を USB で挿してから null-term を開く
  2. Ctrl-A p でポート選択を開き、「＋ 新しいポートを許可する…」 で Enter
  3. ブラウザのダイアログで機器を選んで「接続」
  4. 必要なら Ctrl-A b で bps を合わせる (モデムは 2400 や 9600、マイコンは 115200 が多い)

一度許可したポートは次回からポート選択の一覧に出ます。前回開いたポート・bps・データ形式は、次に開いたとき自動で開き直します。

モデム以外の機器では、URL に ?noprobe を付けて開いてください。既定では接続時にモデム名を調べるため ATI3 を送ります。
例: ?noprobe&baud=115200

モデムでの例

ATI3            モデム名の確認 (接続時にも自動で送ります)
ATDT0           発信 (疑似交換機なら番号は何でもよい)
ATA             着信に応答
Ctrl-A H        DTR を落として回線を切る

機器なしで試す (null-bbs に接続)

モデムがなくても、パソコン通信のホスト局 null-bbs を手元で動かせば、ブラウザからそのまま BBS につなげます。

  1. null-bbs を用意して起動する (Rust が必要) 
    git clone https://github.com/GOROman/null-bbs
cd null-bbs
cargo build --release
cp config.example.toml null-bbs.toml
./target/release/null-bbs
  2. このリンク で null-term を開く (?a=ws://127.0.0.1:5657 で上の画面がつながります)
  3. Chrome が「ローカル ネットワーク上のデバイスへのアクセス」の許可を求めてきたら許可する (許可するまで「接続中」のまま止まります)
  4. バナーが出たら NEW で会員登録、または GUEST でゲストとして入る
  • ポート選択 (Ctrl-A p) で ws:// の URL を選ぶか、直接打ち込んでも接続できます
  • 上下両方をつなぐ (?a=…&b=…) と、2 人分の会員としてチャットや電報を試せます
  • BBS から BYE で抜けると切断され、自動では掛け直しません。Ctrl-A r で再接続します

キー操作 (Ctrl-A のあとに押す)

キー動作
Tab / o / ↑↓上下画面の切替
1 / 2A (上) / B (下) を選択
pポート選択・接続 (新しいポートの許可、ws:// の直接入力もここ)
bbps 設定 (一覧から選ぶか数字で任意値)
r / x再接続 / 切断
HDTR を一瞬落としてモデムの回線を切る (WebSocket では切断)
iモデム名を取得 (ATI3)
u / dファイル送信 / 受信 (XMODEM / XMODEM-1K / YMODEM)
e文字コード切替 (SJIS / UTF-8 / EUC-JP / JIS)
nEnter で送る改行 (CR / CRLF / LF)
hBackSpace を BS / DEL で切替
lローカルエコー
L受信ログの記録 開始 / 停止 (停止するとダウンロード)
c画面消去
z今の画面を最大化 / 戻す
[ / PgUpスクロールバック (Esc で戻る)
Ctrl-A0x01 そのものを送る
?ヘルプ

ファイル転送

  • 送信: Ctrl-A u → ←→ でプロトコルを選んで Enter → ファイル選択ダイアログで選ぶ (YMODEM は複数可)
  • 受信: Ctrl-A d → プロトコルを選んで Enter。受け取ったファイルはブラウザのダウンロードに保存されます (XMODEM は入力欄の名前で保存)
  • 転送中は画面の最下行に進み具合が出ます。Esc で中止します
  • 相手側で送信 / 受信を始めてから (BBS なら「受信を始めてください」と出てから) 操作してください

日本語の入力と貼り付け

  • IME でそのまま日本語を入力できます。確定した文字列が送られます
  • 貼り付け (⌘V / Ctrl-V) もそのまま送れます
  • 文字化けしたら Ctrl-A e で文字コードを切り替えてください (昔のパソコン通信は SJIS、null-bbs は UTF-8。null-bbs につなぐと自動で UTF-8 になります)

URL で既定値を変える

URL の ? 以降で、起動時の設定を変えられます。& でつないで複数指定できます。

指定内容既定
a= / b=その画面の接続先 (ws://…)前回の接続先
baud=bps9600
enc=文字コード: sjis / utf8 / eucjp / jissjis
newline=Enter で送る改行: cr / crlf / lfcr
flow=フロー制御: none / rtsnone
delBackSpace で DEL (0x7F) を送るBS (0x08)
echoローカルエコーを有効にする無効
noprobe接続時に ATI3 を送らない送る

例: ?baud=2400 (2400bps モデム)、?noprobe&baud=115200&enc=utf8 (マイコン)

できないこと・注意

  • Ctrl-W / Ctrl-T / Ctrl-N などブラウザが先に取るキーは送れません
  • フロー制御は none / rts (RTS/CTS) のみです。XON/XOFF は Web Serial にありません
  • bps やデータ形式を変えると、ポートを開き直します
  • ターミナル版にある外部操作 (null-term ctl) はありません
  • タブを閉じると接続は切れます
